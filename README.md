# Valency

Landing page for Valency, a creative and digital growth agency.

One self-contained `index.html`: all CSS and JavaScript are inline and every
path is relative, so the whole folder can be moved anywhere, including pasted
into WordPress, without changing a line.

```
index.html          the entire site
assets/logos/       client logos, white on transparency
assets/services/    the six service banners used by the slideshow
assets/video/       showreel and work videos go here
assets/work/        work stills go here
```

Published with GitHub Pages from the `main` branch.
